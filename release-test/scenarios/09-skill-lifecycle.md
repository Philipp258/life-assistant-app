# 09 — Skill lifecycle

**Goal.** Add a small user skill, confirm it appears in the app, and
confirm the assistant can use it in a later chat.

**Persona.** A user who wants to teach the assistant a tiny reusable
behavior, then verify it actually stuck.

**Done when.** A new user skill exists, the Knowledge/Skills UI shows
it with understandable content and source, and a fresh chat can trigger
the skill's behavior without restating the full instructions. If the
app exposes a natural way to update or remove the skill, try that too;
otherwise just record what lifecycle controls seem missing.

**Rate.** Use judgment. Note whether it was clear how to add, inspect,
trust, edit, use, or clean up a skill, and whether default read-only
skills versus user-installed skills were understandable.
