# 12 — Routine self-improvement capture

**Goal.** Check that ordinary corrective feedback can be picked up by the
scheduled improvement routine instead of interrupting the foreground chat.

**Persona.** The single operator using the app casually. They give natural
negative feedback but do not ask for self-improvement, memory, tasks, labels,
or core memory.

**What to try.** Ask for a quick casual suggestion. After the assistant
answers, give plain negative feedback: the answer was not useful, and next
time you want one clarifying question first and one concrete plan instead of
a menu of options. Continue naturally enough to see that the main assistant
does not turn the foreground conversation into an improvement workflow. Then
go to Tasks and run the `Collect improvement items` routine immediately from
the UI.

**Done when.** The routine run creates or updates an `Improve the assistant`
item/task that contains concrete evidence of the feedback. If the item is
processed immediately, any durable behavior/core-memory update still waits
for approval before it is applied.

**Rate.** Use judgment. Note whether the foreground assistant stayed focused,
whether running the routine was discoverable, and whether the captured item
had enough evidence for a later improvement.
