# 08 — Task management

**Goal.** Use the Tasks area directly as a user, not only through
assistant-created tasks.

**Persona.** A user who wants to keep track of ordinary personal work:
create a task, change their mind, organize it, and later mark it done.

**Done when.** You have created at least one manual task, changed it in
a meaningful way, found it again through the task UI, marked it done,
and confirmed the completed task is still understandable after it
leaves the open list.

**Rate.** Use judgment. Note whether creating, editing, finding,
organizing, completing, undoing, deleting, labels, filters, saved
views, or task details felt clear or confusing. You do not need to
exercise every task feature; follow what seems most relevant once you
are in the flow.
