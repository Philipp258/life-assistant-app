# 06 — Knowledge add and recall

**Goal.** Give the assistant a piece of information that should
persist, then in a separate chat confirm it can recall it.

**Persona.** A user telling the assistant a stable fact about
themselves — for example, dietary preferences, a recurring
appointment, or how they like meetings summarised.

**Done when.** In a fresh chat (not the one where you told it), the
assistant correctly uses the information without being reminded.

**Rate.** Whether the information landed in the right place (core
memory vs. knowledge note vs. nowhere), whether the user got any
confirmation that something was saved, whether recall in a later chat
felt reliable.
