# 07 — Read a local file

**Goal.** Put a small file on the server and ask the assistant to use
its contents — for example, summarise it or extract action items into
a knowledge note.

**Persona.** A user who has dropped a meeting transcript or notes file
into a known path on the machine and wants the assistant to do
something with it.

**Done when.** The assistant has read the file and produced an output
that demonstrably reflects its contents.

**Rate.** Whether file access worked first try, whether the assistant
made it visible that it was reading from the filesystem, whether the
output is faithful to the file, whether anything about permissions or
paths was confusing.
