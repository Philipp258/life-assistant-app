# 07 — Knowledge add and recall

**Goal.** Give the assistant a piece of information that should
persist, inspect it in the knowledge UI, try adding a small manual
knowledge note, make a small edit, then in a separate chat confirm it
can recall the updated information.

**Persona.** A user telling the assistant a stable fact about
themselves — for example, dietary preferences, a recurring
appointment, or how they like meetings summarised.

**Done when.** The assistant-saved information is visible in the
Knowledge tab as reasonable markdown, a small manually-created note
lands somewhere understandable, a small edit through the UI persists,
and in a fresh chat (not the one where you told it) the assistant
correctly uses the updated information without being reminded. Use
whatever fresh-chat affordance the app presents; if none is obvious,
record that as friction.

**Rate.** Use judgment. Note whether saving, finding, editing, and
recalling knowledge felt understandable and trustworthy, especially
whether manually adding knowledge makes it clear where the note lives.
